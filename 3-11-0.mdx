September 8, 2026

#### **Agentic Analysis**

Iris is growing from an assistant that answers questions into one that builds and runs agents alongside you. For our partners and other environment super-administrators, this is available to enable now (_Alpha testing_):

- **Start From a Chat or a Document** - Open a conversation with Iris or hand over a document, then shape what you need in plain language, adding detail and corrections as you go.
- **Launch a Live Agent** - Turn that conversation into a running agent that monitors on its own and logs the data you care about, no scripting required.

---

#### **Model Training**

Good models start with clean training data, so we're cutting down the work it takes to get there:

- **Background Studio** - Pull a frame from any video, not just footage you've already indexed, and let the platform flag the objects it finds. Adjust anything it got wrong, then clear those objects and approve the result in one pass. Clean backgrounds for training, without needing an image editor.
- **Box Selection in Feedback** - Draw a box around an object to segment the whole thing, instead of clicking a point and capturing only the piece your click landed on.

---

#### **Platform Performance**

Fewer data gaps, better visibility into edge performance, and a routine round of security hardening.

- **Uninterrupted Detection** - Video rolling into a new hour no longer drops detections at the top of the hour, so nothing goes unprocessed when the pipeline is running behind.
- **Transcoder Telemetry** - Transcoders now report back to the platform, for better monitoring, alerting, and troubleshooting at the edge.
- **Sharper Iris** - Another round of accuracy and fidelity improvements.
- **Accurate Versioning** - The About page reports the correct platform version again.
- **Platform Hardening** - Patched a batch of dependency-level vulnerabilities across file handling, API request validation, and third-party packages as part of routine security maintenance.
